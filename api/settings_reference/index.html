    Settings Reference¶

    Auto-generated from all *_DEFAULT_SETTINGS variables in DefaultSettings/. Add a new file and it appears here automatically.

    The descriptions come from the Keys: block above each settings dict in the source.

    Tip

    All settings are validated at construction time against the Type, Default, and Constraints shown. See Settings and Stopping Criteria for how to pass them.

    TwoStep¶

    Key Description Type Default Constraints
    jsd_threshold The threshold value for the Jensen-Shannon distance (JSD). If the estimated JSD between the HF and lower fidelity models exceeds this threshold, the lower fidelity model is marked as not accurate enough. The default value is set to 0.7, based on Garbo et al. Multi-Fidelity Adaptive Sampling for Surrogate-Based Optimization and Uncertainty Quantification, 2024. float 0.7 0.0 ≤ value ≤ 1.0
    num_jsd_points The number of points used to estimate the Jensen-Shannon distance (JSD) between the single-fidelity and multi-fidelity models. A higher number of points can lead to a more accurate estimation of the JSD but increases computational cost. int 1000 min: 1
    single_fid_infill The single-fidelity infill strategy used. This infill strategy is used to determine the sample location in the first step of the two-step approach. The name of the infill strategy should be included as a string, e.g., 'EI' for Expected Improvement. str 'EI' one of: GEI, EI, Random

    Optimisation All¶

    Key Description Type Default Constraints
    constant_liar_lie The type of lie to use in the Constant Liar algorithm. str 'min' one of: min, max, mean
    convergence_threshold Threshold for convergence if None this will not be considered (abs(surrogate optimum 'convergence_window' iterations ago - current surrogate optimum) < convergence_threshold). float \| None 1e-06 min: 0.0
    convergence_window Number of iterations to consider for convergence. Calculated as the difference between the surrogate optimum of the current iteration and the surrogate optimum 'convergence_window' iterations ago. Used to determine if the optimisation has converged, based on the convergence_threshold and relative_convergence_threshold. int \| None 5 min: 1
    max_function_calls Maximum number of function calls (all fidelities), if None this stopping criterion will not be used. One HF call is reserved for the final evaluation of the surrogate optimum, which is included. int \| None 1000 min: 1
    max_function_calls_HF Maximum number of function calls for high fidelity, if None this stopping criterion will not be used. One call is reserved for the final evaluation of the surrogate optimum, which is included. int \| None 150 min: 1
    max_iterations Maximum number of iterations, if None this stopping criterion will not be used. Not used by EgoAsync, which has no iterations. int \| None 300 min: 1
    min_infill_value Minimum value for the infill criterion, if None this stopping criterion will not be used. float \| None 1e-06 min: 0.0
    multipoint_algorithm The algorithm to use for multipoint selection if the surrogate has not yet received the new points. 1. "KB" for Kriging Believer 2. "CL" for Constant Liar. str 'KB' one of: KB, CL
    relative_convergence_threshold Relative threshold for convergence, if None this stopping criterion will not be used. abs(surrogate optimum 'convergence_window' iterations ago - current surrogate optimum) / abs(surrogate optimum 'convergence_window' iterations ago) < relative_convergence_threshold. float \| None 1e-06 min: 0.0

    KRG¶

    Extends Smt Surrogate

    All settings from Smt Surrogate are available. The following keys are added or changed:

    Key Description Type Default Constraints
    corr Correlation function type. str 'squar_exp' one of: pow_exp, abs_exp, squar_exp, matern52, matern32
    eval_noise Whether to evaluate noise. bool False —
    hyper_opt Hyperparameter optimisation method. str 'Cobyla' one of: Cobyla, TNC
    is_ri Activate reinterpolation for noisy cases. bool False —
    noise0 Initial noise hyperparameters. list [0.0] —
    noise_bounds Bounds for noise hyperparameters. list [2.220446049250313e-16, 10000000000.0] —
    nugget A jitter for numerical stability. float 2.220446049250313e-14 min: 0.0
    poly Regression function type. str 'constant' one of: constant, linear, quadratic
    pow_exp_power Power for the pow_exp kernel function. This option is set automatically when corr option is squar, abs, or matern. float 1.9 1e-10 ≤ value ≤ 2.0
    seed Random seed for reproducibility. int \| None None —
    theta0 Initial hyperparameters. list [0.01] —
    theta_bounds Bounds for hyperparameters. list [1e-06, 20.0] —
    use_het_noise Heteroscedastic noise evaluation flag. bool False —

    HK¶

    Extends KRG

    All settings from KRG are available. The following keys are added or changed:

    Key Description Type Default Constraints
    corr Correlation function type. str 'squar_exp' one of: pow_exp, cubic_spline, squar_exp
    n_theta_optim_starts Number of differential evolution runs (each with a different seed) used to optimise the hyperparameters theta; the best is kept. int 3 min: 1

    MFK¶

    Extends KRG

    All settings from KRG are available. The following keys are added or changed:

    Key Description Type Default Constraints
    optim_var Whether the variance at HF samples is forced to zero. bool True —
    propagate_uncertainty If True, the variance contribution of LF levels are considered. bool False —
    rho_regr Regression type for rho. str 'constant' one of: constant, linear, quadratic

    RBF¶

    Extends Smt Surrogate

    All settings from Smt Surrogate are available. The following keys are added or changed:

    Key Description Type Default Constraints
    d0 Basis function scaling parameter in exp(-d^2 / d0^2). float 1.0 min: 0.0
    data_dir Directory for loading / saving cached data; None means do not save or load. str \| None None —
    max_print_depth Maximum depth for printing. int 5 min: 1
    poly_degree -1 means no global polynomial, 0 means constant, 1 means linear_trend. int -1 one of: -1, 0, 1
    reg Regularisation parameter. float 1e-10 min: 0.0
